🔵 About

GDGoC PSIT (Google Developer Groups on Campus, PSIT) is a student-led tech community where we learn from each other, build real things, and get comfortable shipping code in the open.

This repository is our shared home base — where our projects, tasks, and contributions will live. We're a mix of beginners and builders, and this repo is meant to be a space where anyone can jump in, learn how a real dev workflow operates, and leave their mark on something bigger than a solo assignment.

<br>
🔴 What is Open Source?

If you're new to this — open source simply means the code is public, and anyone can read it, use it, improve it, and contribute back to it.

Instead of one person working alone, a project grows through contributions from many people — each person picking up an issue, fixing a bug, adding a feature, or improving docs, then submitting their changes for review via a Pull Request (PR).

🟢 How Tasks Will Work

Once issued, tasks will follow this flow:

Browse the Issues tab for open tasks
Claim a task by commenting on the issue (avoids duplicate work)
Fork the repo & create a new branch for your task
Build your solution
Submit a Pull Request referencing the issue
Get reviewed, iterate if needed, and get merged 🎉

We'll tag issues by difficulty and type once live — e.g.

good-first-issue frontend backend bug feature

so you can pick what suits your comfort level.

🔵 Contributing

We welcome contributions from all members, regardless of experience level.

Be respectful and collaborative — we're all here to learn
Write clear commit messages
Keep PRs focused (one task/fix per PR)
Ask questions! No question is a bad question in this community

A full CONTRIBUTING.md with detailed guidelines will be added alongside the first batch of tasks.
